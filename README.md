# Daily Scribe
Online Services for Kindle Scribe and other devices. The kindle scribe is pretty locked down by Amazon. However, you can send it pdfs via email. This will be a service to send you pdfs and even respond to your handwritten responses. Here is a list of potential services:

- [x] Kanji a day
- [ ] Track eating 
- [ ] Read a classic novel
- [x] Daily crossword 
- [ ] DND 5e Campaign
- [x] CBC News
- [x] [BBC News](https://www.bbc.co.uk/news/10628494)
- [x] [RTE News](https://www.rte.ie/feeds/rss/?index=/news/&limit=100)
- [x] Home Assistant summary 

## Goal
Have a functioning SaaS that people a minimal amount for. The cost of the service 
should about cover the operational expenses.
